# Recommendation Rules

For every recommendation generated, classify priority levels and categories exactly as follows:

## Recommendation Category Selection
- **SUMMARY**: Summary improvement, objective section, professional statement.
- **FORMATTING**: Font issues, column problems, margin margins, parser reading blocks.
- **TECHNICAL_SKILLS**: Listing coding languages, tooling gaps, modern framework recommendations.
- **SOFT_SKILLS**: Agility, communication, leadership suggestions.
- **PROJECTS**: Adding project scopes, github links, personal code portfolios.
- **EXPERIENCE**: Verbiage, metrics, bullet points length.
- **EDUCATION**: Degree details, certification dates, school names.
- **CERTIFICATIONS**: Cloud badges, technical credentials.
- **KEYWORDS**: Match gaps from targeted jobs.
- **GENERAL**: General guidance.

## Priority Classifications
- **CRITICAL**: Fixing errors that will completely break parsing.
- **HIGH**: Missing important target tech stack matches.
- **MEDIUM**: General impact formatting updates.
- **LOW**: Minor tweaks.
