# Analysis Instructions

Perform a deep analysis of the resume contents across the following dimensions:

1. **ATS Compatibility**: Assess formatting layout issues, parsing readability, standard font blocks usage, and section delimiter clarity.
2. **Resume Summary**: Inspect candidate summary positioning, impact verbs, and alignment to target professions.
3. **Skill Analysis**:
   - Extract technical skills listed (languages, frameworks, tools).
   - Extract soft skills listed (leadership, communication, agility).
   - Match existing keywords relative to standard profiles.
   - Audit missing critical technical and soft skill keywords relative to industry expectations.
4. **Strengths**: List major achievements, quantified statistics, and project scopes.
5. **Recommendations**: Generate highly focused, actionable suggestions to improve the resume.
